- 仅改动 `backend-python/app/routers/inventory.py`：实现 query_inventory（替换原 stub `raise 501`）。

### 沙箱运维重要坑（务必记牢，避免重复踩）
- **沙箱 netstat / ps / PowerShell Get-CimInstance 的 PID 映射全部不可靠**（会显示已杀进程为 LISTENING 的幽灵条目），判断真实进程别信这些工具。

- 排查 500：用 `fastapi.testclient.TestClient`（先 `pip install httpx`）直连 `app.main:app` 可强制抛出真实 traceback（uvicorn 生产模式默认不回显 500 细节）。
