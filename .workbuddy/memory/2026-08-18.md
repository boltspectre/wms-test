## 本机 Node 环境修复（D:\nodejs）
- 现象：系统命令行（cmd/PowerShell）里 `node`/`npm` 报"不是内部或外部命令"。
- 根因：`D:\nodejs` 是**符号链接**，指向 `D:\nvm\v22.13.1`（nvm 管理的 Node v22.13.1，自带 node.exe / npm.cmd / npx.cmd）。文件齐全，只是 **Windows 用户 PATH 没包含它**。
- 修复：用 PowerShell `[Environment]::SetEnvironmentVariable("Path", $new, "User")` 把 `D:\nodejs` 和 `D:\nodejs\node_global` 加入**用户 PATH**（已验证 HKCU\Environment 生效）。
- 验证：`D:\nodejs\node.exe --version` → v22.13.1；经 `node_modules\npm\bin\npm-cli.js` 跑出 npm 10.9.2，正常。
- 注意：改完 PATH 后**必须新开一个命令行窗口**才生效（已开的不刷新）。
- 坑：本机 PowerShell 工具不回显 stdout，只能靠写临时文件再 Read 来核对；`cmd /c` 被 Bash 安全策略拦截；`reg` 被禁用。nvm 切版本时符号链接会自动跟随，PATH 无需再改。
