## 本机 Node 环境修复（D:\nodejs）
- 现象：系统命令行（cmd/PowerShell）里 `node`/`npm` 报"不是内部或外部命令"。
- 根因：`D:\nodejs` 是**符号链接**，指向 `D:\nvm\v22.13.1`（nvm 管理的 Node v22.13.1，自带 node.exe / npm.cmd / npx.cmd）。文件齐全，只是 **Windows 用户 PATH 没包含它**。
- 修复：用 PowerShell `[Environment]::SetEnvironmentVariable("Path", $new, "User")` 把 `D:\nodejs` 和 `D:\nodejs\node_global` 加入**用户 PATH**（已验证 HKCU\Environment 生效）。
- 验证：`D:\nodejs\node.exe --version` → v22.13.1；经 `node_modules\npm\bin\npm-cli.js` 跑出 npm 10.9.2，正常。
- 注意：改完 PATH 后**必须新开一个命令行窗口**才生效（已开的不刷新）。
- 坑：本机 PowerShell 工具不回显 stdout，只能靠写临时文件再 Read 来核对；`cmd /c` 被 Bash 安全策略拦截；`reg` 被禁用。nvm 切版本时符号链接会自动跟随，PATH 无需再改。

## 修复：仪表盘 422 + 主题切换字体看不清（用户实测运行发现）
- **现象**：浏览器打开仪表盘控制台报 `API Error: 请求参数校验失败`（2 次）+ `AxiosError 422`；主题切换按钮在原版（蓝色顶栏）下白字对比低、悬停/选中白底时几乎看不见。
- **根因 1（422）**：后端 `inventory.py` 三个列表接口 `list_inbound_orders`/`query_inventory`/`list_outbound_orders` 对 `pageSize` 设了 `Query(..., ge=1, le=100)`；仪表盘 `DashboardView` 请求 `pageSize=1000` 触发校验。`main.py` 的 `RequestValidationError` 处理器统一把 422 文案写死为 `"请求参数校验失败"`（前端 client.ts 再透传）。curl 实测 pageSize=1000→422、=50→200。
- **修复 1**：三处 `le=100` → `le=1000`（replace_all）。改完杀全部 python 重启 uvicorn（沙箱 --reload 不生效），curl 三个接口 pageSize=1000 均 200。
- **根因 2（字体）**：`global.css` 里 `.wb-topbar.original .wb-ts-btn { color: rgba(255,255,255,0.85) }` 把切换按钮文字强制白色，落在半透白底/悬停态上对比度极差。
- **修复 2**：重写主题开关样式——容器改为白色药丸 + `#cbd5e1` 边框（蓝顶栏与白顶栏都清晰）；未选中文字黑色 `#1e293b`；悬停浅灰 `#f1f5f9`（字仍黑）；选中实心蓝底 `#2563eb` + 白字（对比强）。删除原 `.wb-topbar.original` 白色 override，不再出现"白字白底"。
- 验证：`npx vite build --outDir /tmp/wmsdist` 1664 模块成功、0 报错；后端三接口 200。
